# ion·inf — программы для учеников

Небольшая адаптивная страница с официальной загрузкой LibreOffice и короткой инструкцией для Windows и macOS. Python и PyCharm отмечены как будущие разделы.

Продакшен: [soft.ioninf.ru](https://soft.ioninf.ru). Основной домен `ioninf.ru` зарезервирован под общую экосистему ion·inf.

## Быстрый запуск

Никакие зависимости не нужны. Можно дважды нажать на `index.html` или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Что настроить перед публикацией

Telegram для помощи настроен на `https://t.me/im_ion`.

Кнопка LibreOffice запускает прямое скачивание официального установочного файла The Document Foundation. Для macOS можно выбрать Apple Silicon или Intel. Номер версии, тексты и ссылки находятся в начале `script.js` — обновите их при выходе новой версии LibreOffice.

## Публикация

### GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы проекта.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через несколько минут GitHub покажет готовую публичную ссылку.

### Netlify Drop

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите туда всю папку проекта.
3. Netlify сразу выдаст публичную ссылку; домен можно изменить в настройках сайта.

### Любой обычный хостинг

Загрузите `index.html`, `styles.css`, `script.js` и папку `assets` в корневую папку сайта. Сборка на сервере не требуется.

### Текущий сервер

Продакшен использует Caddy в Docker. Серверные файлы находятся в `deploy/`: основной Caddyfile и дополнительный Compose-файл, который подключает `/var/www/ioninf-soft` только для чтения.

## Структура

- `index.html` — содержимое страницы;
- `styles.css` — оформление и адаптивность;
- `script.js` — выбор системы и смена инструкции;
- `assets/favicon.svg` — иконка вкладки браузера.
