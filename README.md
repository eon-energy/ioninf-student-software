# Программы для занятий с Ионом

Публичный ученический справочник: сначала Python, затем PyCharm; LibreOffice — для отдельных занятий с таблицами и документами.

Продакшен: [soft.infa-ion.ru](https://soft.infa-ion.ru). Старый адрес [soft.ioninf.ru](https://soft.ioninf.ru) сохраняет путь и параметры при перенаправлении 308.

## Локальный запуск и проверка

Нужен Node.js 22+ (CI использует 24). Серверной части у сайта нет.

```sh
npm ci
npx playwright install chromium
npm run build
npm run serve
```

Открыть http://127.0.0.1:4174. Не открывайте исходный HTML двойным кликом: модулям и каталогу нужен HTTP. На macOS тесты могут использовать установленный Chrome; CI использует отдельный Chromium.

```sh
npm test
npm run test:downloads
node scripts/check-downloads.mjs --verify-libreoffice
npm run test:production
```

Последняя команда сравнивает продакшен с локальной сборкой, MIME, кеширование, CSP, 404 и редирект. Проверка полных SHA-256 LibreOffice перед релизом читает около 983 МБ по сети, не сохраняет и не запускает установщики. Обычная проверка использует HEAD и небольшие byte-range запросы, проверяет каждый HTTPS-переход и допустимый домен. MIME и сигнатура файла не заменяют проверку подписи ОС.

CI запускает браузерные проверки на push/PR и по понедельникам проверяет загрузки. Отчёты сохраняются как артефакты Actions; сломанные ссылки завершают проверку ошибкой. Автоматического обновления программ или публикации из CI нет.

## Источники истины

- `catalog.json` — версии, причины закрепления, требования, размеры, адреса установщиков, контрольные суммы, разрешённые домены, дата проверки и владелец.
- `guide-data.js` — тексты, стабильные ID шагов, исходные снимки и координаты стрелок. Версии в тексте подставляются из каталога; фактическая версия на снимке хранится отдельно.
- `model.js` — выбор файла, адреса шагов, единое правило прокрутки.
- `script.js` — общий контроллер трёх программ.
- `index.template.html` + `scripts/build.mjs` — HTML, включая полноценную текстовую инструкцию без JavaScript.
- `styles.css`, `DESIGN.md`, `AGENTS.md` — оформление и контракт.
- `tests/` + `scripts/check-*.mjs` — исполняемые проверки.

Сборка создаёт только `dist/`: HTML и разрешённые ресурсы с хешами содержимого. Большие исходные портреты, макет LibreOffice, старые вырезки, документы ревью, .git и инструменты не публикуются. Старые исходники оставлены в истории Git; дублирующих контроллеров и HTML с вручную записанными версиями нет.

## Политика версий

Ответственный: Ион, владелец курса и сайта. Контакты: [Telegram](https://t.me/im_ion).

Python закреплён по запросу преподавателя. PyCharm — стабильная версия, подтверждённая официальным API на дату проверки. LibreOffice оставлен в версии курса; известная более новая версия сама по себе не повод менять инструкцию.

Для обновления:

1. Проверить официальный источник релиза и поддерживаемые ОС, дату и требования.
2. Одним изменением каталога обновить версию, размеры файлов, контрольные суммы и дату. Не менять номер вручную в HTML, JS-контроллере или README.
3. Пройти ссылки: протокол каждого редиректа, домен, MIME, размер, сигнатуру; для LibreOffice — полный SHA-256 и наличие зеркала в официальном списке.
4. В чистой поддерживаемой Windows и macOS установить программы, сверить каждый пункт инструкции, запустить пример. Не отключать защиту ОС.
5. Добавить реальные новые скриншоты, их точную версию/ОС/дату и результаты проверки. До этого предупреждение о старых снимках обязательно.
6. Запустить тесты, просмотреть desktop/mobile, опубликовать только `dist/`, проверить продакшен.

На 16.10.2026 чистая установка текущих версий на Windows/macOS не выполнена в этой задаче: `nativeInstallVerifiedAt: null`. Это не заменено браузерными тестами. Windows-снимки PyCharm показывают 2025.2.1.1, а не текущую загрузку; подпись повторяется у каждого снимка. Для Mac они явно обозначены как ориентир Windows. LibreOffice временно имеет честную текстовую инструкцию по [официальному руководству](https://www.libreoffice.org/installation-instructions/), без изображения макета.

Прогресс хранится в sessionStorage текущей вкладки. Ссылка на шаг переживает открытие в новой вкладке; перезагрузка восстанавливает текущий выбор. Сайт не сканирует установленные программы: финальная готовность PyCharm — только явное подтверждение ученика.
