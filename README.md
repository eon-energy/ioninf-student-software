# ion·inf — программы для учеников

Небольшая адаптивная страница с официальными установщиками LibreOffice, Python 3.13.16 и PyCharm 2026.2.3 для Windows и macOS. Инструкции ведут от установки до первого запуска Python-кода.

Продакшен: [soft.ioninf.ru](https://soft.ioninf.ru). Основной домен `ioninf.ru` зарезервирован под общую экосистему ion·inf.

## Быстрый запуск

Никакие зависимости не нужны. Можно дважды нажать на `index.html` или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Что настроить перед публикацией

Telegram для помощи настроен на `https://t.me/im_ion`.

Кнопка «Установить» раскрывает выбор Windows/macOS. После выбора система показывает прямую загрузку официального файла The Document Foundation и подходящую инструкцию. Apple Silicon подходит для M1 и всех более новых процессоров, включая M5; для старых Mac доступна версия Intel. Номер версии, тексты и ссылки находятся в начале `script.js` — обновите их при выходе новой версии LibreOffice.

## Публикация

### GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы проекта.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через несколько минут GitHub покажет готовую публичную ссылку.

### Netlify Drop

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите туда всю папку проекта.
3. Netlify сразу выдаст публичную ссылку; домен можно изменить в настройках сайта.

### Любой обычный хостинг

Загрузите `index.html`, `styles.css`, `script.js`, `guides.js` и папку `assets` в корневую папку сайта. Сборка на сервере не требуется.

### Текущий сервер

Продакшен использует Caddy в Docker. Серверные файлы находятся в `deploy/`: основной Caddyfile и дополнительный Compose-файл, который подключает `/var/www/ioninf-soft` только для чтения.

## Структура

- `index.html` — содержимое страницы;
- `styles.css` — оформление и адаптивность;
- `script.js` — раскрытие установки, выбор системы и смена инструкции;
- `guides.js` — установщики Python/PyCharm, главы инструкций, координаты стрелок и просмотр снимков;
- `assets/guides/` — 23 оригинальных скриншота пользователя для инструкций;
- `AGENTS.md` — постоянные правила frontend-работы в проекте;
- `DESIGN.md` — дизайн-токены и визуальный контракт;
- `assets/im-ion-cutout-final.png` — портрет для главного экрана;
- `assets/im-ion-portrait.png` — иконка вкладки;
- `assets/fonts/bad-script-v18.ttf` — локальный шрифт личной подписи;
- `assets/installation-reference.png` — исходник изображений инструкции;
- `assets/browser-downloads.png` — подсказка, где найти загруженный файл в браузере;
- `assets/favicon.svg` — оранжевая иконка вкладки с буквой i.

## Python и PyCharm

Проверено 16 октября 2026:

- [Python 3.13.16](https://www.python.org/downloads/release/python-31316/): рекомендованный Windows x64 `.exe`, не embeddable-архив; универсальный `.pkg` для Mac. Версия закреплена для занятий.
- [PyCharm, стабильный релиз](https://data.services.jetbrains.com/products/releases?code=PCP&latest=true&type=release): 2026.2.3; `.exe` для Windows x64, отдельные `.dmg` для Apple Silicon и Intel. Версия не обновляется автоматически: при обновлении сверить официальный API, ссылки и инструкции, затем изменить `setupCatalog` и версию в `index.html`.
- [Требования и установка PyCharm](https://www.jetbrains.com/help/pycharm/installation-guide.html): базовые функции остаются бесплатными, Pro для первых занятий не нужен.

Исходные фотографии не перерисованы: рамки, стрелки и номера накладываются в SVG в исходной системе координат. Повторяющиеся фотографии опущены. На снимках PyCharm 2025.2, об этом прямо сказано в инструкции. На Mac установка описана текстом; общие шаги создания проекта и запуска иллюстрируются снимками Windows.

Проверка перед публикацией: `node --check guides.js`, `node --check script.js`; пройти обе системы, переключение Intel/Apple Silicon, все главы и шаги, увеличение и Escape, мобильную ширину 375px. Проверить официальные файлы HEAD-запросами без скачивания дистрибутивов.
